# ATFT HQ

A standalone internal operations portal for Arletta The Friendly Trader.

## Included in this starter

- Responsive, premium dark-mode app shell
- Desktop sidebar and mobile navigation
- COO-focused dashboard
- Needs Attention overview
- Daily schedule
- Quick actions
- Announcements and recently updated SOPs
- Command palette UI (`Cmd/Ctrl + K`)
- Reusable color tokens and component structure

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Suggested deployment

Deploy this repository independently to Vercel. During development it can use a Vercel preview domain. Later, connect it to `hq.arlettathefriendlytrader.com` and add a Portal link to the public ATFT website.
